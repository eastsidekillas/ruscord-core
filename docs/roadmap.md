# План MVP

Цель: рабочая бета, где голос, видео и демонстрация экрана работают в личках и на
серверах. Разработка локальная до беты; перед первыми пользователями нужен
закрытый staging с публичным IP (TURN и реальные сети локально не проверить).

| Шаг | Что | Статус |
|---|---|---|
| 1 | Каркас: конфиг, логи, health, docker compose, CI, документация | готово (PR #1) |
| 2 | Схема БД (миграции goose), аутентификация: регистрация, вход, ротация refresh, тикеты WS, лимиты | готово (PR #2) |
| 3 | `internal/perm` + табличные тесты | готово (PR #3) |
| 4 | REST: серверы, каналы, роли, инвайты, сообщения, связи; outbox + NATS | готово (PR #4, #5, #7, #8; аудит PR #9) |
| 5 | Gateway v1 + перевод клиента `ruscord-fe` на ядро | 5a готово (PR #10, #11, права для клиента PR #12); 5b — план в [plans/mvp-client-features.md](plans/mvp-client-features.md): 5b-1 «печатает» и статусы — готово (PR #14), 5b-2 файлы и профиль — в ревью, 5b-3 клиент |
| 6 | Voice: голосовые каналы, звонки в личках, демонстрация экрана | — |
| 7 | E2EE личных звонков, антиабьюз | — |
| 8 | Desktop на Tauri (глобальный push-to-talk), нагрузочные тесты, staging, закрытая бета | — |

Метрики выхода в открытую бету: подключение к голосу ≥ 98 %, время до звука
p95 < 3 с, задержка звука p95 < 250 мс в регионе, доставка сообщения p99 < 500 мс,
RESUME ≥ 95 % реконнектов.
