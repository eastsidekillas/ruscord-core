API ядра (`docs/api.md`). Тексты ошибок взяты из кода ядра и клиента.

## Чего на экранах нет и почему

- **Вложения, реакции, журнал аудита, чужие ники.** Биты прав есть
  (`ATTACH_FILES`, `ADD_REACTIONS`, `VIEW_AUDIT_LOG`, `MANAGE_NICKNAMES`),
  а методов в API нет: ник меняется только свой. В редакторе ролей эти
  права не показаны.
- **Камера.** Кнопка на экране голосового канала — заготовка под 6d.
- **Светлая тема** — только в токенах дизайн-системы.
- **Раскладка для телефона** — позже (решение владельца).

## Перенос в клиент

Часть 1 (ruscord-fe #42): первый сценарий — вход, приглашение, сервер с
каналом, голос в списке, панель голоса, чат, участники. Сверено со
скриншотами макетов.

Часть 2 (ruscord-fe #44–#46): друзья, личка, группы.

Часть 3 (2026-11-02): настройки аккаунта — профиль и статус, устройства и
безопасность (ruscord-fe #47); создание сервера и канала, меню, ник (#48);
настройки сервера и роли (#49); участники, баны, приглашения (#50); права
канала (#51); ошибки и состояния. Все экраны холста перенесены.

Настройки голоса и видео (2026-11-09, ruscord-fe `settings-voice`, план
`docs/plans/settings-part-1.md`): новое меню настроек, разделы «Голос»,
«Камера», «Соединение», проверка микрофона и камеры вне звонка, рация.

## Расхождение с клиентом

Решено при переносе ролей (2026-11-02): права вложений, реакций, журнала
аудита и «Менять ники участников» в редакторе ролей не показываются, у
роли не сбрасываются.

Профиль с настроением (2026-11-10, ruscord-fe `settings-profile`, план
`docs/plans/settings-part-3.md`): в разделе «Профиль» — сетка из восьми лиц
долобеба, фраза, срок и цвет обложки, справа карточка «Как вас видят
другие». Та же карточка открывается по нажатию на человека. Статус
присутствия из формы убран: он меняется в панели внизу. Настроение видно в
списках участников сервера и группы.
