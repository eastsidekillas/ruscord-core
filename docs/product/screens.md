# Экраны Okno по функциям ядра (2026-11-01)

Холст «Okno — экраны», стиль C (ADR-0027). На экранах только то, что есть в
API ядра (`docs/api.md`). Тексты ошибок взяты из кода ядра и клиента.

| Сценарий | Что умеет ядро | Экран (страница холста) |
|---|---|---|
| Вход | `POST /auth/login`, `invalid_credentials`, лимит | Вход (Аккаунт) |
| Регистрация | `POST /auth/register`, ошибки полей, `email_taken` | Регистрация (Аккаунт) |
| Профиль и статус | имя, «о себе» до 190, аватар до 8 МиБ, статусы online / idle / dnd / invisible | Профиль (Аккаунт) |
| Устройства | список сессий, завершить, выйти на всех других (пароль) | Устройства и безопасность (Аккаунт) |

| Друзья | заявка по имени, принять, отклонить, отменить, удалить, блок | Друзья (Друзья и лички) |

## Чего на экранах нет и почему

- **Вложения, реакции, журнал аудита, чужие ники.** Биты прав есть
  (`ATTACH_FILES`, `ADD_REACTIONS`, `VIEW_AUDIT_LOG`, `MANAGE_NICKNAMES`),
  а методов в API нет: ник меняется только свой. В редакторе ролей эти
  права не показаны.
- **Камера.** Кнопка на экране голосового канала — заготовка под 6d.
- **Раздел «Голос и видео»** в настройках — по отзывам первой проверки.
- **Светлая тема** — только в токенах дизайн-системы.
- **Раскладка для телефона** — позже (решение владельца).

## Расхождение с клиентом

В клиенте редактор ролей показывает все права, включая вложения, реакции и
журнал аудита и «Менять ники участников». Убрать их или оставить — решить
при переносе дизайна.
