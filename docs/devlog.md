## 2026-10-29 · Шаг 1: каркас

**Сделано**
- Go-модуль, точка входа с выбором ролей (`RUSCORD_ROLES`), конфиг из env с
  валидацией: вне dev обязательны пароль Valkey и ключи LiveKit, секрет LiveKit
  не короче 32 символов.
- `/healthz` (процесс жив) и `/readyz` (Postgres, Valkey, NATS). Вне dev
  `/readyz` не отдаёт текст ошибок, чтобы не светить адреса и логины.
- docker compose: Postgres 18, Valkey 9, NATS 2.15 с JetStream, LiveKit v1.13.10.
  Всё на 127.0.0.1, секреты генерирует `make env`.
- CI: vet, тесты с `-race`, golangci-lint, поднятие compose-стека и проверка `/readyz`.
- Документация: архитектура, план, ADR 0001–0010, допущения, чек-лист ревью.

**Узнали**
- Redis 8 распространяется под AGPLv3/SSPL/RSAL. Для self-hosting это не мешает,
  но чтобы не думать о лицензиях вообще, взяли Valkey (BSD) — см. ADR-0010.
- Образ Postgres 18 хранит данные в `/var/lib/postgresql/18/...`, том монтируется
  на `/var/lib/postgresql`.
- Зависимости (pgx, go-redis, nats.go) требуют Go 1.26, поэтому `go.mod` на 1.26.
