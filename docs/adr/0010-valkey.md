# ADR-0010: Valkey вместо Redis

- Статус: принято
- Дата: 2026-10-29

## Контекст
Redis с версии 8 распространяется под AGPLv3/SSPL/RSAL. Для self-hosting это
не запрещено, но владелец проекта хочет избегать лицензионных вопросов.

## Решение
Valkey (BSD-3, форк Redis под Linux Foundation). Протокол совместим, клиент
go-redis тот же. LiveKit для мультинода должен работать с ним как с Redis (допущение A7, проверить на staging).

## Пересмотреть, если
Понадобится функция, которая есть только в Redis.
