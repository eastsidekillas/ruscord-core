# ADR-0005: E2EE личных звонков, MLS позже

- Статус: принято
- Дата: 2026-10-29

## Контекст
DTLS-SRTP шифрует медиа только до SFU; сервер видит медиа в открытом виде.

## Решение
MVP: E2EE в личных звонках через LiveKit E2EE (шифрование кадров AES-GCM),
ключи устройств X25519/Ed25519, эфемерные ключи на звонок, код безопасности для
сверки. После беты: групповой обмен ключами по MLS (RFC 9420), как DAVE у Discord.

## Последствия
Нет серверной записи, шумоподавления и модерации медиа. Без сверки кода
безопасности не защищает от подмены ключей сервером, интерфейс это говорит.

## Пересмотреть, если
Юридические требования в целевой юрисдикции делают E2EE невозможным, или
WebView Tauri не поддерживает encoded transforms (допущение A5).
