# ADR-0002: Ядро на Go, модульный монолит

- Статус: принято
- Дата: 2026-10-29

## Контекст
Старый бэкенд на Django Channels (~2,6 тыс. строк) не годится для realtime:
рассылка статусов всем, сокет на каждый чат, состояние звонка только на клиенте.
Команда: два участника, код в основном пишет ИИ. Старые данные не переносим.

## Решение
Один Go-репозиторий и бинарь с модулями `api`, `gateway`, `voice`, `workers`;
`RUSCORD_ROLES` выбирает, какие модули запускает процесс.

## Альтернативы
- Django REST + Go gateway: два языка на бэке для двух человек.
- Elixir/Phoenix: лучший fan-out, но порог входа и нет официального LiveKit SDK.
- Rust: медленнее итерации.
- TypeScript + mediasoup: см. ADR-0001.

## Последствия
Один язык, строгие типы, простой деплой. Админку придётся сделать самим.

## Пересмотреть, если
Профилирование покажет, что gateway упирается в язык, а не в fan-out: тогда
вынести gateway в отдельный сервис, не трогая api.
