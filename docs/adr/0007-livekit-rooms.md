# ADR-0007: Имена комнат LiveKit

- Статус: принято
- Дата: 2026-10-29

## Решение
`call:<call_id>` для звонков в личках и группах, `voice:<channel_id>` для
голосовых каналов серверов. Токен на вход живёт 60 секунд.

## Почему
В старом проекте комната совпадала с ID канала, и токен прошлого звонка
подходил к следующему. Отдельный ID звонка даёт историю и таймауты.
