# ADR-0006: Отправка сообщений через REST, доставка через gateway

- Статус: принято
- Дата: 2026-10-29

## Решение
`POST /channels/{id}/messages {content, nonce}`; gateway только доставляет события.

## Почему
Идемпотентность, лимиты, коды ошибок и ретраи проще в HTTP; gateway остаётся
простым и масштабируется отдельно.

## Пересмотреть, если
Задержка отправки p95 больше 150 мс из-за накладных расходов HTTP.
