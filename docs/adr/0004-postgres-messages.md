# ADR-0004: Сообщения в Postgres, UUIDv7

- Статус: принято
- Дата: 2026-10-29

## Решение
Сообщения в Postgres 18, ключ `uuidv7()` (сортируется по времени), индекс
`(channel_id, id DESC)`, курсорная пагинация.

## Альтернативы
ScyllaDB/Cassandra (путь Discord): оправдано на миллиардах строк, лишнее на старте.
Snowflake BIGINT: компактнее, но нужен генератор и уход от UUID.

## Последствия
Одна БД, транзакции вместе с outbox, понятные бэкапы.

## Пересмотреть, если
Таблица больше ~1 млрд строк, запись больше ~5 тыс./с или p99 чтения истории
выше 50 мс: сначала партиционирование по времени, потом отдельное хранилище.
