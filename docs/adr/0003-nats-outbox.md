# ADR-0003: События — outbox + NATS JetStream

- Статус: принято
- Дата: 2026-10-29

## Контекст
Gateway должен получать события о записях в БД без потерь и дублей при сбоях.

## Решение
Запись и событие пишутся в одной транзакции (таблица `outbox`), relay публикует
в NATS JetStream по subject `guild.<id>`, `channel.<id>`, `user.<id>`.

## Альтернативы
Redis Pub/Sub (теряет сообщения при отключении), Kafka (тяжело в эксплуатации
для двух человек), прямая публикация из обработчика (теряется при падении между
коммитом и публикацией).

## Последствия
Гарантия «событие после коммита», replay для resume. Ещё один сервис в стеке.

## Пересмотреть, если
Больше 50 тыс. событий в секунду или нужна потоковая аналитика.
