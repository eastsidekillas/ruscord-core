# ADR-0028: Название бренда Zvonilka, маскот «долобеб»

- Статус: принято; заменён ADR-0030 (placemood)
- Дата: 2026-11-02

## Контекст

ADR-0027 выбрал направление айдентики C с временным названием Okno.
Окончательное название оставалось за владельцем.

## Решение

Решение владельца 2026-11-02, утверждено:

1. **Название бренда — Zvonilka.** Заменяет рабочее Ruscord и временное
   Okno.
2. **Маскот и внутренний персонаж — «долобеб».**

Направление айдентики C (цвета, шрифт, знак-окно, дизайн-система)
остаётся как в ADR-0027.

## Последствия

- В интерфейсе название задаётся в одном месте:
  `ruscord-fe/src/shared/config/brand.ts` (сейчас там ещё `okno`).
  Нужно также поменять:
  - надпись на обложке и в README дизайн-системы;
  - заставку и заголовок вкладки (`index.html`);
  - макеты на холсте.
- Репозитории и код (`ruscord-core`, `ruscord-fe`, переменные `RUSCORD_*`)
  пока не переименовываются: это отдельная работа, решение за владельцем.
- Проверка товарного знака (ФИПС, классы 09, 38, 42) и доменов для
  Zvonilka не проводилась (product/naming-and-identity.md).
- Образа маскота пока нет.

## Пересмотреть, если

- Проверка знака покажет, что название занято в нужных классах.
