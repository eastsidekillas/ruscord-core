# ADR-0008: Хостинг — self-hosted, один регион

- Статус: принято
- Дата: 2026-10-29

## Контекст
Аудитория: геймеры и разработчики без привязки к стране. Онлайн неизвестен.
До беты разработка локальная.

## Решение
Один регион рядом с первыми пользователями: одна нода ядра, одна медиа-нода,
управляемые Postgres и Valkey. Если основная аудитория в РФ, провайдер в РФ
(152-ФЗ).

## Пересмотреть, если
Больше 30 % звонков с RTT до медиа-ноды выше 120 мс: вторая медиа-нода в другом
регионе, ядро остаётся в одном.
